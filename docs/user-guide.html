User Guide

How to load subject-historic-current-comparison, connect its data sources and fill in its settings.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select subject-historic-current-comparison from the templates list.

2. Data sources

  • Access to a EarthRanger data source, set up as a connection

3. Settings

The run form asks for these. Fields with a default can be left as they are.

4. Run it and find the results

The workflow writes its files to the results folder the runner gives it (ECOSCOPE_WORKFLOWS_RESULTS), and shows its dashboard when it finishes. The dashboard has one Movement Tracks map per subject: the current period in the subject's EarthRanger colour (blue if it has none), the previous period in grey.
